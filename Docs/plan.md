# Project Plan

## Project Overview
This project is the creation of a two page website for KJNdustries Warehouse Integration, a B2B consulting company focused on helping clients connect enterprise systems, warehouse management systems, and warehouse automation technologies. The site will be published through GitHub Pages and supported by planning documentation housed in the same repository.

## Risk Analysis Using TAME

### Risk 1: Running out of time before the deadline
- **Impact:** High
- **Probability:** Medium
- **TAME Strategy:** Mitigate
- **Response:** Keep the project tightly scoped, one stylesheet, and the required documentation only. Build the structure first, then style it (don't overdo it!), then finalize the docs.

### Risk 2: Missing required files or repository structure
- **Impact:** High
- **Probability:** Medium
- **TAME Strategy:** Eliminate
- **Response:** Use the assignment checklist we were given. Just build this around the repository structure from the start. I am going to root website files plus the `docs/` folder with the three required Markdown files.

### Risk 3: Broken navigation or publishing issues on GitHub Pages
- **Impact:** Medium
- **Probability:** Medium
- **TAME Strategy:** Mitigate
- **Response:** Test both pages locally and after publishing. Verify README links, navigation, and GitHub deployment all work before submitting.

### Risk 4: Scope creep from adding extra features
- **Impact:** Medium
- **Probability:** Medium
- **TAME Strategy:** Accept / Mitigate
- **Response:** Please just stay aligned to the written exclusions and only implement what the scope requires. I have a bad habit of trying to do too much and getting overwhelmed.

### Risk 5: Incomplete or weak documentation
- **Impact:** High
- **Probability:** Medium
- **TAME Strategy:** Mitigate
- **Response:** I already drafted a lot of the documentation in the prior weeks assignment so I think we're good here.
